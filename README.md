#  Deepfake Face Detection

Kho lưu trữ này chứa mã nguồn và tài liệu định nghĩa cho dự án phát hiện khuôn mặt giả mạo (Deepfake Face Detection), tập trung vào việc ứng dụng Deep Learning và các mô hình thị giác máy tính tiên tiến.

---

##  Cấu trúc dự án

* **`Project Definition.pdf`**: Tài liệu định nghĩa chi tiết về mục tiêu, phạm vi và phương pháp thực hiện dự án.
* **`Notebook/`**: Thư mục chứa các Jupyter Notebook (`.ipynb`) ghi lại toàn bộ quá trình:
  * Khám phá và tiền xử lý dữ liệu.
  * Thử nghiệm, huấn luyện và đánh giá các mô hình (ResNet, EfficientNet, ConvNeXt, v.v.).

---

##  Hướng dẫn nhanh

1. **Xem tài liệu định nghĩa:** Bạn có thể click trực tiếp vào file [Project Definition.pdf](https://github.com/Ichangg/Deepfake-Face-Detection/blob/main/Project%20Definition.pdf) để đọc báo cáo chi tiết.
2. **Khám phá Notebook:** Truy cập vào thư mục `Notebook/` để xem mã nguồn, các biểu đồ trực quan hóa và kết quả thử nghiệm trực tiếp trên giao diện GitHub.
